重启，不必重新开始查看实际状态 →
重启程序以后，之前的生活状态还在吗？
Life 会恢复已经保存的状态和事件。没有正在执行的活动时，当前状态仍然可以是 IDLE。

持续保存不代表关机期间仍在活动；自主活动执行与主动联系尚未开放。

经历可以积累，过时的事实也可以修正。

记住，也允许改变管理记忆 →
/chiyo_memory correct 记忆ID 我现在更喜欢红茶
纠正后，后续召回应采用“更喜欢红茶”的新事实。记忆 ID 需要先从 list 返回的条目中选取。

也可用 delete 停止采用某条记忆；原始聊天与审计仍保留，不能代替彻底擦除。

四大核心能力

虚拟世界、身体、持续生活与记忆，是 nyairo 在聊天和工具能力之外构建的四个核心方向。

01WORLD

虚拟世界

在有限世界里拥有具体位置与可见环境，让对话有场景。第一版接入世界服务，提供只读观察。

了解世界 →
02BODY

身体状态

读取姿态、持物情况与身体信号。身体拥有独立状态，回答依据实际观察，而非临时编写的设定。

了解身体 →
03LIFE

持续生活

独立保存日常事件与生活状态，重启后接续已有记录。当前支持状态连续性，自主活动仍在后续规划中。

查看状态 →
04MEMORY

经历与记忆

从个人经历中召回相关内容，支持查看、纠正和停止采用。让记忆随经历更新，并保留明确的数据边界。

管理记忆 →

此外，可按需连接认知观察与个人文档空间。认知判断只作观察，文档保存需要资源服务与授权。查看完整功能状态。

未来规划 · 真实住得下来的生活日常

玩 Galgame 最怕通关后屏幕一黑，角色就永远停在结局里。nyairo 的目标是让她拥有真正流淌的时间：有属于自己的小房间，平时会主动关心你，需要时还能切成 Agent 协助工作。

P1 · 当前基础

世界、生活与记忆的基础连接

个人记忆与生活状态本地保存，重启后继续读取；连接独立世界服务后，可观察位置、姿态与身体信号。自主活动尚未开放。

当前版本 (v0.1)
P2 · 规划重点

住得下的小房间与随身手机

书桌、床头、窗台六大实体区域留痕（做到一半的草稿、书签、咖啡杯）；拥有随身手机（相册、日记备忘）与不依赖催促的独立长篇创作。

v2.0 规划重点
P3 · 中期演进

主动关切提问与独特做事偏好

告别被动等待，在日常偶遇中主动问起你关心的事；在做事失败的反例中总结避坑法则，逐渐形成自己的小心愿与独特审美个性。

v3.0 中期探索
P4 · 远期愿景

换电脑不丢回忆的无损搬家

就算以后换了新电脑、换了操作系统，或者升级了底层更强的大模型，她的小房间、日记相册、作品与所有经历都能完整搬过去，长久陪伴。
