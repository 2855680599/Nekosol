# 记忆行为



删除表示永久停止召回和停止进入聊天上下文，原始证据仍保留。纠正必须由同一绑定用户的直接输入提供，模型没有控制账本的写入工具。



聊天命令：`/memory list` 显示最近十条可选择的用户证据及 ID；`/memory delete ID` 停止使用；`/memory correct ID 正确内容` 用明确新内容替换旧内容。命令本身先进入只追加 M0，再按该事件 ID 幂等执行控制。失败会明确返回失败，不会回复成功。



控制账本必须提前由部署者初始化，方法为 `MemoryControlLedger(path,evidence,owner=transport_owner_id,conversation=bound_conversation_id).initialize()`。配置 `CHIYO_MEMORY_CONTROL_DB` 后，缺失、损坏或身份绑定失败都排除历史记忆和历史上下文；不自动重建丢失账本。



删除/纠正会从新的对话时间点继续装配历史上下文，清除可能已经复述旧事实的历史回复。长期召回过滤目标证据、同轮证据和此前的助手自述；仍可用其它用户直接证据。纠正文本保留来源，删除纠正本身后不会复活旧内容。



M0/M1/M2 的原始和派生记录不会被物理擦除。M37 是唯一长期记忆上下文来源，Legacy MEMORY.md/USER.md 默认不会注入。关系文件是独立人格/关系输入，不是可删除聊天记忆。



回滚必须保留控制账本并使用认识这份账本的版本；禁止回到重新注入 Legacy 的版本。备份恢复也必须先恢复最新控制账本。
