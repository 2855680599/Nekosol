v0.1.0-rc4 Persistent Digital Individual Runtime

让聊天拥有连续性 与可管理的记忆

基于完整 Hermes，增加长期记忆、生活状态、世界身体观察和个人文档。记忆可以跨会话使用、查看和纠正；第一版通过命令行或消息机器人聊天，认知判断只给建议，不自动行动。

查阅使用教程 快速上手指南 GitHub
$ bash scripts/install.sh

MEMORY / LIFE

记忆与生活连续性

记忆可跨会话召回、纠正及停止使用；生活状态与入站审计持续保存。READY 表示装配可用，IDLE 不代表已在自主执行。

PRIVACY / DATA

隐私与数据控制

个人数据保存在自己的运行目录。远程模型与消息平台会处理所需内容；停止召回不等于擦除原始聊天或其他平台副本。

查阅规范 →
SHADOW / NOT EXECUTION

Shadow 认知与边界

真实模型可对明确请求作观察判断，受预算和故障保护。Shadow 不执行动作，也不主动联系；自主闭环仍是后续工程。
