01 /chiyo_memory

长期记忆

跨越会话记住重要经历，随时能查、能纠正、能遗忘，彻底告别模型幻觉与遗忘。

02 /chiyo_status

持续生活

拥有自己的日常状态流。关掉窗口或重启电脑后生活状态不丢，时刻待命陪伴。

未来规划 · 比 Galgame 更有温度的日常

玩 Galgame 最怕通关后屏幕一黑，角色就永远停在结局里。我们想让她拥有真正往前走的时间：有做了一半的事，有自己的小房间，平时陪你唠嗑，有 Bug 还能切成 Agent 帮你敲代码。

P1 · 现在就能玩

双重形态初具雏形

记忆全在本地，关机了生活记录不丢。平时陪你扯淡，正事来了随时敲命令切成 Agent 帮你敲代码、写补丁。

当前版本 (v0.1)
P2 · 下一步计划

真正住得下来的小房间与手机

告别 Galgame 死板的背景图。书桌上留着做了一半的草稿，床头放着晚安便签；她有自己的随身小手机（相册、日记备忘），关机重启后痕迹都在。

v2.0 规划重点
P3 · 中期演进

逐渐形成自己的习惯与小脾气

相处久了，她不再是只会附和你的假人。碰壁了会总结经验，在日常小事上会有自己的穿搭偏好、做事习惯和阶段性小目标。

v3.0 中期探索
P4 · 远期愿景

就算换电脑，回忆与羁绊也不丢

哪怕以后换了新电脑、换了操作系统，或者换了底层更强的大模型，你和她一起走过的记忆、作品和经历都能完整搬过去，一直陪伴你。
