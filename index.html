未来规划 · 真实住得下来的生活日常

玩 Galgame 最怕通关后屏幕一黑，角色就永远停在结局里。nyairo 的目标是让她拥有真正流淌的时间：有属于自己的小房间，平时会主动关心你，需要时还能切成 Agent 协助工作。

P1 · 当前基础

本地记忆与双重形态闭环

记忆全在本地 SQLite，关机重启日常记录不丢。平时是默契的生活伙伴，遇到棘手开发任务时一键切成 Agent 协同写代码。

当前版本 (v0.1)
P2 · 规划重点

住得下的小房间与随身手机

书桌、床头、窗台六大实体区域留痕（做到一半的草稿、书签、咖啡杯）；拥有随身手机（相册、日记备忘）与不依赖催促的独立长篇创作。

v2.0 规划重点
P3 · 中期演进

主动关切提问与独特做事偏好

告别被动等待，在日常偶遇中主动问起你关心的事；在做事失败的反例中总结避坑法则，逐渐形成自己的小心愿与独特审美个性。

v3.0 中期探索
P4 · 远期愿景

换电脑不丢回忆的无损搬家

就算以后换了新电脑、换了操作系统，或者升级了底层更强的大模型，她的小房间、日记相册、作品与所有经历都能完整搬过去，长久陪伴。
